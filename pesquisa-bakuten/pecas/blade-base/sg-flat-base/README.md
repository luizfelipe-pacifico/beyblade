## Formato
Base baixa com ponta flat de plástico; sucessora da Flat Base das 4-layer.

## Função em batalha
Velocidade e altura baixa, boa para upper attack. Considerada ultrapassada pela Storm Grip e pela SG Metal Flat 2.
